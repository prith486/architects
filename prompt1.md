# Part 1: Asset Generation Prompts & Preparation (`1_asset_prompts.md`)

To perfectly replicate the tactile, premium hover effect across a 12-image grid, you must first generate the correct assets. This file contains the precise AI image generation prompts (optimized for tools like Midjourney or DALL-E 3) to create your project thumbnails and the crucial 3D embossed pattern overlay. 

## 1. The 3D Embossed Pattern Tile (The Hover Overlay)
This is the most critical asset. We need a seamless, bas-relief style pattern that mimics physical material. Once generated, you will need to remove the background using an editing tool to make the shadows and highlights transparent, allowing the CSS background color to show through.

**Prompt for the 3D Pattern:**
> Seamless repeating pattern, 3D embossed monogram logo featuring intertwined geometric letters, bas-relief sculpture style, monochromatic white on white, studio macro photography, soft dramatic side lighting casting deep shadows and crisp highlights, highly tactile texture like molded plaster or heavy pressed cotton paper, clean architectural aesthetic, 8k resolution, ultra-detailed --tile
